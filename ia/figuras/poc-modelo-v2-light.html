Ciclo de entrenamiento

para cada fragmento en INTERNET:        // 1 ir a la nube y leer    tokens = tokenizar(fragmento)        // 2 clasificar en la mesa    v = vector(palabra_clave)            // 3 escribir sus números    error = probar(tokens, v)            // 4 adivinar y medir    estante[hueco] = ajustar(v, error)   // 5 acomodarguardar(estante)                        // el modelo base

Simplificación didáctica con valores escritos a mano. Cada tarjeta representa solo una parte de los parámetros: en un modelo real los parámetros no se reparten palabra por palabra; son miles de millones de números compartidos (los vectores de las palabras son solo una parte) que se ajustan todos a la vez. El robot escribe aquí el vector ya ajustado; en un entrenamiento real los números empiezan al azar, el error se calcula sobre la predicción y se corrigen poco a poco, con billones (10¹²) de tokens leídos. Los textos no se guardan como archivos, aunque un modelo puede memorizar fragmentos que se repiten mucho.
