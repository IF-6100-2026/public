Qué pasa

    El prompt: lo que hay en la librería del harness

    La aplicación

    Muestra lo que escribe el usuario y lo que recibe. No sabe qué skills hay ni cuáles se cargaron.

    El harness

    Arma el prompt: instrucciones base, descripciones de skills, historial y el pedido. Carga una skill cuando el modelo la pide.

    El modelo

    Solo lee el prompt que recibe. Una skill no lo cambia ni lo hace más capaz: solo agrega instrucciones al contexto.

    Las skills

    Carpetas con un SKILL.md (nombre, descripción e instrucciones) y recursos. No hacen nada solas: son texto que se carga cuando hace falta.

    Valores ilustrativos escritos a mano: el tamaño de cada libro es en unidades y el límite es 60. En algunos productos el propio modelo lee el archivo con una herramienta; aquí se muestra al harness cargándolo. Las instrucciones de una skill pueden ignorarse o aplicarse mal: no garantizan la calidad.
